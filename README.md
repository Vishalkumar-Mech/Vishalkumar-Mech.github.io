# Vishal Kumar — GitHub Resume Website

A responsive, single-page resume/portfolio website built with plain HTML and CSS.

## Files

- `index.html` — resume/portfolio content
- `style.css` — responsive design and print styling

## Publish on GitHub Pages

1. Create a GitHub repository named `<your-username>.github.io`.
2. Upload `index.html` and `style.css` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your site will be available at `https://<your-username>.github.io`.

## Before publishing

Replace:
- `YOUR_EMAIL@example.com`
- GitHub profile URL
- LinkedIn profile URL
- Phone number
- Exact employer name/dates if needed
- Exact college/university name and marks/CGPA

The **Print / Save as PDF** button lets visitors print the web resume to PDF from the browser.
